# Support

Need help with this template? Here's where to go, in order:

## 1. Check the README first

Most setup problems (env variables, Supabase config, OAuth callback URLs) are
covered in the [README](README.md) — re-check the Troubleshooting / setup
sections before asking. It's usually the fastest fix.

## 2. "How do I…" questions → GitHub Discussions

For setup help, usage questions, or "how do I add X" — post in
[GitHub Discussions](https://github.com/faiyazpilot/webapp-template/discussions).
That's where the community can see and answer your question.

## 3. Bugs in the template → GitHub Issues

Open an issue **only** for bugs in the template itself — something that is
broken for everyone, not just your setup. If it works in a fresh clone but
not in your project, it's a Discussions question, not an issue.

## 4. Security vulnerabilities → SECURITY.md

**Never** report security problems in a public issue or discussion.
Follow the email instructions in [SECURITY.md](SECURITY.md) instead.
