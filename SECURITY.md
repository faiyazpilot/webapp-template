# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Scope

- **In scope:** vulnerabilities in the template itself (auth bypass, RLS gaps,
  XSS, etc.) — report these by email as described below.
- **Out of scope:** issues in *your* deployed copy or your customizations —
  ask in [GitHub Discussions](https://github.com/faiyazpilot/webapp-template/discussions) instead.
- **Explicitly out of scope:** the anon key being visible in the browser is by
  design — see the README security section.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email: faiyaz@business-pilot.ai

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

You'll get a response within 48 hours. If confirmed, a fix will be released as soon as possible.

Reporters are credited in the changelog unless they prefer otherwise.
